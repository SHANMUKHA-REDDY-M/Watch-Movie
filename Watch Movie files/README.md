# 🎬 Watch Movies  

**Watch Movies** is a full-stack Movie Ticket Booking System that allows users to explore theatres, view movies, book tickets, and manage bookings seamlessly. Built with modern web technologies, it offers role-based access for users, theatre owners, and administrators.

---

## 🧭 Overview  
**Watch Movies** provides a fast, secure, and user-friendly experience to browse, book, and manage movie tickets online — from seat selection to digital ticket generation.

---

## ✨ Features  

### 🎟️ User Features  
- Browse currently playing and upcoming movies  
- Filter by genre, location, language, or rating  
- Choose theatre, timing, and seat preference  
- Make secure online payments  
- View and download PDF tickets  
- Manage booking history  

### 🎭 Theatre Owner Features  
- Manage movie listings and showtimes  
- View and track bookings in real time  
- Access earnings dashboard  

### 🛠️ Admin Features  
- Manage users, theatres, movies, and transactions  
- Review reports and logs  
- Handle system-wide configurations

## ⚙️ Setup Instructions  

### 🔹 Local Setup
1. Clone the repository  
   ```bash
   git clone https://github.com/SHANMUKHA-REDDY-M/Watch-Movies.git
   cd Watch-Movies
   ```
2. Install dependencies  
   ```bash
   npm install
   ```
3. Run the server  
   ```bash
   node backend/server.js
   ```
4. Open your browser at `http://localhost:3000`
