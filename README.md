# Watch Movie

Full-stack Movie Ticket Booking project (frontend + mock backend) — responsive and role-based (user, theatre owner, admin).

## What's included
- Frontend: `pages/`, `css/`, `js/`, `assets/`
- Backend (mock/Express): `backend/`
- Data: `api/`, `data/`
- Invoices: `invoices/`
- Docs: `docs/Testing.md`

## Quick Start (frontend only)
Serve the project root with a static server:
```bash
npx http-server .
# open http://localhost:8080/pages/index.html
```
